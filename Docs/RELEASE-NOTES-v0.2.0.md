## SaberW 2 v0.2.0 — MVP завершён

Сжатие текста и кода для чатов с LLM без потерь: словарь кодов CJK Extension A, round-trip побуквенный.

Что вошло в версию:
- Фразовое сжатие с точными диапазонами: разделители (". ", ", ", переводы строк, двойные пробелы) сохраняются round-trip.
- Опция ignoreComments: чекбокс окна; маркеры //, /* */, <!-- -->, #; защиты URL (://) и C-препроцессора.
- Живые метаданные словаря: счётчики сжатий/распаковок/экспортов, даты применения, sizeBytes по ТЗ 6.10; автосохранение после «Для бота»; авто-чекбокс «Первое сообщение» по ТЗ 18.8.
- Экспорт боту: конкатенация и экранирование всех токенов значения (ТЗ 10.2); разделитель блоков с защитой от коллизий (ТЗ 18.6); блоки recursion и supplement; гейт ступени 2 minFrequencyForStep2 (ТЗ 7/9.2).
- ИД словаря: 6 символов из алфавита 79 (ТЗ 5, R-002); нейтральные кандидаты S=0 допускаются (ТЗ 7, R-003).
- Прогресс-бар появляется после 10 секунд расчёта (ТЗ 6/22.1.4).
- Окно «О программе»: 6 языков (ru, en, zh, fr, es, pt), спиннер размера шрифта, кнопка копирования в буфер.
- 40 автотестов зелёные; CI гоняет тесты на каждый push и публикует jar/exe/portable-zip в Releases.

Ассеты: SaberW-2-0.2.0.jar (любая ОС с Java 21+), SaberW-2.exe (Windows), портативный zip (Windows, JRE 21 внутри).

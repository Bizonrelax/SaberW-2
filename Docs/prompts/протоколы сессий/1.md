Протокол сессии
Протокол начала: git remote add origin https://github.com/Bizonrelax/SaberW-2.git (если нет); git fetch origin; git checkout ptadc || git checkout -b ptadc origin/ptadc; git log --oneline -3 → в отчёт. Токен: <ТОКЕН> — использовать ТОЛЬКО в команде push одноразовым URL вида https://x-access-token:<ТОКЕН>@github.com/Bizonrelax/SaberW-2.git HEAD:ptatimon-1; не писать токен в файлы, .git/config и отчёт.
**ПРАВИЛО ВЫБОРА ЧАТА (Для владельца и кодера):**
- **НОВЫЙ ЧАТ** выбирается для 95% задач. Контейнер эфемерный, старый чат не сохраняет файловую систему, а только перегревает контекст. Новая сессия = свежий `git clone`, чтение промта и чистая работа.
- **СТАРЫЙ ЧАТ** используется ТОЛЬКО для "дожима" (continuation), если предыдущая сессия прервалась исчерпанием квоты вызовов (статус REMAINING) и нужно выполнить 2-3 финальных шага без повторного бутстрапа окружения.
Протокол конца: перед завершением обязательно push HEAD:ptadc (даже при красных тестах); строка отчёта PUSHED: да/нет. Merge в main только через PR и только при зелёных тестах.
Далее выполни файл: Docs/prompts/2026-10-17-bot-exporter-2.md …(далее текст указателя как раньше)
Не использовать launch4j-maven-plugin; для упаковки использовать jpackage + zip в GHA.
